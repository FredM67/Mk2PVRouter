# Mk2PVRouter

Code and documentation have been moved to other repositories.

For a **single phase version**, please see [PVRouter-1-phase](https://github.com/FredM67/PVRouter-1-phase).

For a **three-phase version**, please see [PVRouter-3-phase](https://github.com/FredM67/PVRouter-3-phase).

## Documentation

The documentation is published at <https://fredm67.github.io/Mk2PVRouter/>:

- **stable** (branch `main`): the documentation of the released firmware, at `/Mk2PVRouter/`;
- **dev** (branch `dev`): the documentation of the unreleased firmware, at `/Mk2PVRouter/branch/dev/`. It is rebuilt on each push to `dev` and every night, with the latest `dev` of the firmware repositories;
- **legacy** (branch `legacy`): the documentation of the former mono/tri boards, at `/Mk2PVRouter/branch/legacy/`.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the branch to use for a change.
