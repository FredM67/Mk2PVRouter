Installation du module mk2Wifi

⏱️ Temps estimé : 30–45 minutes

🔧 Niveau de difficulté : Débutant

📋 Prérequis

Avant de commencer ce chapitre :

☐ Chapitre ⚠️ Sécurité — À Lire Absolument Avant de Commencer lu et compris
☐ Chapitre Module mk2Wifi lu
☐ Carte principale assemblée et testée
☐ Cavalier TEMP configuré selon votre choix (voir Configuration des cavaliers)
☐ Routeur programmé avec SERIAL_OUTPUT_TYPE = SerialOutputType::IoT dans config.h (9600 bauds, 7E1), le mode par défaut : à remettre si vous êtes passé en mode lisible pour les premiers tests
☐ Câble USB-C disponible
☐ Ordinateur avec port USB

Soudure des barrettes

Le module mk2Wifi est livré avec ses composants CMS assemblés. Les deux barrettes femelles TRIG_EXT et UART_EXT (1×06, 2,54 mm) doivent être soudées par l’utilisateur ; la carte principale porte les barrettes mâles correspondantes.

  1. Insérez chaque barrette femelle par la face arrière du module (face sans composants, où sont sérigraphiés les cadres TRIG_EXT et UART_EXT) ; les soudures se font côté composants. Une barrette soudée sur la mauvaise face obligerait à brancher le module à l’envers

  2. Soudez une broche, vérifiez que la barrette est perpendiculaire au PCB

  3. Soudez les broches restantes

À faire

Photo à fournir — barrettes TRIG_EXT et UART_EXT soudées et perpendiculaires au PCB.

Installation physique

Si le module n’est pas encore programmé, faites d’abord la programmation initiale, qui se fait module débranché de la carte principale.

Avertissement

COUPER L’ALIMENTATION SECTEUR avant toute manipulation.

Le routeur doit être hors tension pour brancher ou débrancher le module mk2Wifi.

Avertissement

Avant de brancher le module, vérifiez que le cavalier V sel. de la carte principale est dans sa position d’usine 1–centre (3,3 V). Les broches GPIO de l’ESP32-C6 ne tolèrent que 3,3 V — une tension de 5 V sur ces lignes endommagerait le module (voir Configuration des cavaliers).

  1. Vérifiez l’orientation : composants du module vers le haut (barrettes femelles dessous), TRIG_EXT du module sur TRIG_EXT de la carte principale et UART_EXT sur UART_EXT, la broche 1 (GND, pastille carrée) de chaque barrette du module en face de la broche 1 (GND) du connecteur de la carte principale. Le module ne doit pas être retourné.

  2. Enfoncez le module fermement mais sans forcer sur les deux connecteurs de la carte principale (TRIG_EXT et UART_EXT)

  3. Vérifiez que le module est bien en contact sur toute la longueur des deux connecteurs

Avertissement

Le module peut être branché à l’envers — les connecteurs ne possèdent pas de détrompeur. Vérifiez visuellement l’orientation et l’alignement avant d’enfoncer le module. Un branchement inversé peut endommager le module et/ou la carte principale.

Programmation initiale (USB-C)

Le premier chargement du firmware se fait obligatoirement via le connecteur USB-C. Les mises à jour suivantes pourront se faire via OTA (WiFi).

Avertissement

Ne pas connecter l’USB-C lorsque la carte mk2Wifi est branchée sur la carte principale.

Débranchez le module de la carte principale avant de connecter le câble USB-C.

Astuce

Pour le routeur triphasé, le configurateur génère le YAML ESPHome du module, cohérent avec le config.h du routeur, et indique les ponts de soudure à fermer. Pour le routeur monophasé, ce YAML n’est pas encore généré (voir Configurateur du firmware — Monophasé) ; le Gist de référence peut servir de point de départ.

Procédure

  1. Coupez l’alimentation secteur du routeur, puis débranchez le module de la carte principale (si connecté)

  2. Connectez le câble USB-C entre le module et votre ordinateur

  3. Si le module n’est pas détecté, passez en mode téléchargement : maintenez le bouton Boot (SW1) enfoncé (GPIO9 à l’état bas) pendant la mise sous tension, puis relâchez

    Astuce

    Il s’agit du petit bouton-poussoir marqué « Boot » sur la carte. Si le module est déjà alimenté par USB, débranchez et rebranchez le câble USB-C tout en maintenant le bouton enfoncé.

  4. Chargez le firmware : pour ESPHome, voir ESPHome et Home Assistant ci-dessous

  5. Après le chargement, débranchez le câble USB-C

  6. Routeur hors tension, rebranchez le module sur la carte principale

Note

L’ESP32-C6 dispose d’un contrôleur USB-série/JTAG intégré : aucun programmateur externe n’est nécessaire.

ESPHome et Home Assistant

Le YAML généré par le configurateur se charge dans ESPHome (tableau de bord ou ligne de commande) :

  • il demande ESPHome 2026.10.0 ou plus récent (min_version), première version qui intègre le composant mk2pvrouter ;

  • les mots de passe et clés n’y figurent pas : ils sont lus dans un fichier secrets.yaml, qui doit définir wifi_ssid, wifi_password, wifi_fallback_password, api_encryption_key, esphome_ota_password, esphome_web_server_username et esphome_web_server_password ;

  • la première installation se fait par le câble USB-C, module débranché de la carte principale (procédure ci-dessus) : dans le tableau de bord ESPHome, « Install », puis « Plug into this computer » (ou ESPHome Web depuis le navigateur) ; les suivantes se font sans fil (OTA, voir plus bas) ;

  • une fois le module sur le réseau WiFi, Home Assistant le détecte (intégration ESPHome) : ajoutez-le en saisissant la clé api_encryption_key ; la connexion passe par l’API native d’ESPHome, chiffrée avec cette clé ;

  • si le module ne trouve pas le réseau WiFi, il ouvre son propre point d’accès de secours, dont le nom commence par le nom convivial de l’appareil (mot de passe wifi_fallback_password), qui permet de saisir le bon réseau ;

  • le journal série d’ESPHome est désactivé (baud_rate: 0) : l’UART sert à la liaison avec le routeur. Les journaux se consultent par WiFi.

Important

Le module ne comprend que la sortie série IoT du routeur (9600 bauds, 7E1) : vérifiez SERIAL_OUTPUT_TYPE dans le config.h du routeur.

Mises à jour OTA

Après le premier chargement par USB-C, les mises à jour du firmware peuvent se faire sans fil via WiFi (OTA).

  1. Assurez-vous que le module mk2Wifi est connecté à votre réseau WiFi

  2. Lancez la mise à jour OTA depuis votre outil de développement (avec ESPHome, installation sans fil protégée par le mot de passe esphome_ota_password)

  3. Le module redémarre automatiquement après la mise à jour

Note

La connexion USB-C n’est nécessaire que pour le premier chargement du firmware. Toutes les mises à jour suivantes se font via OTA.

Écran OLED (optionnel)

Le module mk2Wifi dispose d’un connecteur OLED (Molex SL 1×4) pour un écran I2C.

Note

Le bus I2C de l’écran OLED est local au module mk2Wifi. Il n’est pas partagé avec la carte principale. Cela signifie que l’écran OLED du mk2Wifi est indépendant du connecteur OLED de la carte principale.

En mode triphasé, l’écran OLED de la carte principale n’est pas disponible (broches A4/A5 utilisées pour la mesure). L’écran OLED via le mk2Wifi est alors la seule option d’affichage.

Le YAML généré par le configurateur déclare le bus I2C (bus_oled) mais ne pilote pas l’écran : le composant display est à ajouter vous-même.

Vérification

✅ Point de Contrôle — Module mk2Wifi

Après l’installation, vérifiez :

☐ Module correctement enfoncé sur les deux connecteurs (TRIG_EXT et UART_EXT)
☐ LED témoin D1 allumée lorsque la carte principale est sous tension
☐ Firmware chargé avec succès (premier chargement via USB-C)
☐ Mesures du routeur (puissance instantanée…) mises à jour dans Home Assistant ou dans les journaux ESPHome (par WiFi)
☐ Connexion WiFi établie (si le firmware WiFi est configuré)
